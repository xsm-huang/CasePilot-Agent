## 本轮验证

- V1 收尾加固后的完整后端数据库／进程回归：220 项通过、无跳过（110.20 秒）；包含新增共享总预算、四阶段真实调用边界、阶段恢复、源码指纹、第一轮人工语义闸门、冻结数据强校验、显式 ambiguous 调用对账，以及既有 pgvector、checkpoint 和强杀窗口。
- 前端／契约：23 项通过（契约 5、前端 18）；新增审核依据完整展示、引用请求 A 慢 B 快隔离和事件穷尽处理。TypeScript、Vue/Vite 构建与契约生成一致性通过。
- Ruff 和差异格式检查通过。当前模型首次 capability 尝试在受限执行环境中以 `ConnectError` 停止，仅预占 1 次模型请求，未继续 JSON 或 Embedding；该调用已按“确认已消耗”对账，累计账本为模型 3 次、Embedding 0 次并保持 active。原 run 的 capability 仍为 `inProgress`，禁止用 `--resume` 猜测重放。
- 切换 `glm-5.3-flash` 后完整后端数据库回归：184 项通过、无跳过（144.07 秒），静态检查通过；模型专属配置和内部思考回传的改动见 [模型适配与切换说明](模型适配与切换说明.md)。本次项目修改未追加真实模型请求。
- 历史阶段的全量数据库回归：182 项通过、无跳过（152.73 秒）；新增引用前后段落、分页与完整回合、四个独立进程崩溃窗口和评测预算保护。后续仅校正了最小门禁的严格布尔检查及中文卡片名称，针对性检查见验收记录。
- 历史前端／契约基线：22 项通过（契约 5、前端 17），新增历史分页迟到时保留新到消息；连续事件、任务隔离、未知响应重试、冲突重同步及刷新恢复均通过。
- TypeScript、Vue/Vite 构建通过；契约生成与 Python 模型同步。静态检查、最终回归及迁移记录随本轮开发记录更新。
- 浏览器在 UUID 隔离数据库与显式测试适配器下验证会话创建、审核通过、报告、引用页码和原文。测试替身仅在测试入口注入，生产没有假模型环境开关。

没有向开发业务 schema 植入测试向量。旧模型历史门禁曾出现 ConnectError 和 ReadTimeout，累计预占模型 2 次；当前 `glm-5.3-flash` 门禁又在受限执行环境中出现一次 ConnectError，并已保守计入累计用量。未取得当前模型的有效 capability 响应，未执行后续批量真实评测。测试只清理自己创建的 UUID schema。PyPDFLoader 集成仍有 langchain-community 弃用提示，后续替换须保留现有页码和 PDF 边界测试。
